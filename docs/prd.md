## 1. 概述

工艺路线设计器是电瓷智造 ERP 的核心模块，用于定义和管理电瓷产品的**制造工艺流程**。用户通过可视化的方式，将标准工序节点拖拽到画布上，连接成完整的工艺路线，并配置每个节点的执行参数。

**一句话：让工艺工程师像画流程图一样设计生产路线。**

## 5. 业务规则

### 5.1 路线约束

- BR-01: 一条工艺路线**必须有且只有一个起始节点**（起点标识）
- BR-02: 一条工艺路线**必须有且只有一个结束节点**（终点标识）
- BR-03: 一条工艺路线可以跳过某些标准工序（非所有产品都需要全部 8 道工序）
- BR-04: 工序间的连接不能形成**循环回路**（DAG 约束）
- BR-05: 每个工序节点**只能有一个出线**（除非是并行分支节点）
- BR-06: 质检节点必须有两条出线（通过/不通过）

### 5.2 参数规则

- BR-07: 每个工序节点必须配置**责任人角色**（如成型工、烧成工）
- BR-08: 可配置**标准工时**（分钟/件）、**温度范围**、**压力范围**等数值参数
- BR-09: 参数可设置为"必填"或"可选"
- BR-10: 支持参数模板，同类型工序共用一套参数

### 5.3 状态规则

- BR-11: 路线有状态流转：**草稿 → 待审核 → 已发布 → 已归档**
- BR-12: 已发布的路线不可编辑，只能新建版本
- BR-13: 已归档的路线不可被引用到新订单

## 6. 异常流程

| 场景 | 处理方式 |
|------|---------|
| 删除被引用的路线 | 阻止删除，提示"该路线正在被 N 个订单使用" |
| 保存时存在未连接节点 | 警告"存在未连接的节点"但允许保存（标记为草稿） |
| 删除标准工序库工序 | 不允许删除标准的 8 道工序，仅可禁用 |
| 节点参数超出安全范围 | 红色警告标注，不允许保存为"已发布"状态 |
| 网络/数据库写入失败 | 自动保存到本地缓存（localStorage），下次打开提示恢复 |

## 7. 边界条件

| 条件 | 处理 |
|------|------|
| 画布为空（无节点） | 显示空状态引导："从左侧拖拽工序开始设计" |
| 超过 50 个节点 | 性能警告，建议拆分路线 |
| 节点名称超过 20 字 | 截断显示，hover 展示全称 |
| 参数值为负数 | 拒绝保存，提示"参数值不能为负数" |
| 同名路线 | 保存时提示"已存在同名路线，是否覆盖？" |
| 无权限用户打开编辑器 | 显示只读模式，工具栏禁用 |

## 8. 验收标准

### 8.1 功能验收（可量化）

| # | 验收项 | 验证方式 |
|---|--------|---------|
| AC-01 | 从工序面板拖拽任意工序到画布，生成对应节点 | 手动拖拽测试 |
| AC-02 | 节点间可拖线连接，删除连线后连接断开 | 手动测试 |
| AC-03 | 双击节点弹出参数编辑面板，保存后参数持久化 | 编辑 + 重新打开确认 |
| AC-04 | 保存后的路线重新加载，节点位置和连接关系完全还原 | 保存 → 关闭 → 打开 |
| AC-05 | 8 道标准工序预置在工序库中，可直接使用 | 检查左侧工序面板 |
| AC-06 | 画布支持鼠标滚轮缩放（0.25x ~ 4x） | 滚轮操作 |
| AC-07 | 画布支持鼠标拖拽平移 | 拖拽操作 |
| AC-08 | 新建路线默认为"草稿"状态 | 检查状态标签 |
| AC-09 | 发布路线后，编辑器变为只读模式 | 发布 → 尝试编辑 |
| AC-10 | 路线循环连接被检测并阻止 | 画最后一次连线时验证 |
| AC-11 | 无节点时显示空状态引导 | 新建路线 → 查看画布 |
| AC-12 | 路线保存到 SQLite，重启后数据不丢失 | 重开应用验证 |

### 8.2 性能验收

| # | 验收项 | 指标 |
|---|--------|------|
| AC-13 | 20 个节点以内的路线加载时间 | ≤ 500ms |
| AC-14 | 拖拽节点操作帧率 | ≥ 30fps |
| AC-15 | 画布缩放/平移无卡顿感 | 目测流畅 |
