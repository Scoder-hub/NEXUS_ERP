# 自动化功能扫描与版本迭代方案（按钮/页面完成度盘点）

> 目标：自动扫描 Electron/Web 界面上的页面与按钮，产出“完成度清单”，让团队明确**哪些功能已实现、哪些未实现/仅占位**，并据此规划版本迭代。

---

## 1. 最终产出（团队可直接用来排期）

建议固定产出 3 份文件（每次版本迭代更新）：

1. `docs/feature-inventory.md`：功能清单（模块 → 页面 → 功能点/按钮 → 完成度）
2. `docs/feature-scan-report.md`：自动扫描报告（本次扫描时间、覆盖页面数、失败点、截图/日志）
3. `docs/version-plan.md`：版本规划（v0.x.0 的任务列表、优先级、风险、验收标准）

---

## 2. 完成度口径（统一语言，避免扯皮）

每个“页面/按钮/功能点”统一用以下状态（可扩展）：

- ✅ **已完成**：点击/操作有明确结果（弹窗/跳转/请求/数据变化），且无明显错误
- 🟡 **部分完成**：UI 有，但缺少边界/异常/校验/权限等；或仅部分路径可用
- 🔜 **占位/未实现**：按钮存在但无效果、提示“coming soon”、或直接被写死禁用
- ❌ **故障**：可操作但报错/崩溃/严重异常（需要修复）
- 🧪 **需要人工确认**：自动化无法判断（例如依赖外部环境/权限/复杂输入）

---

## 3. 自动扫描怎么做（Playwright 两层策略）

### 3.1 第一层：页面覆盖扫描（Page Coverage）
目标：尽可能“遍历页面”，统计可访问页面与核心 UI 是否渲染正常。

实现方式（建议）：
- 从路由配置/菜单配置中提取路径（比盲爬更稳定）
- Playwright 逐页打开并做基础断言：
  - 页面主标题/关键元素存在
  - 无致命 console error
  - 无白屏/崩溃

### 3.2 第二层：按钮/交互扫描（Action Coverage）
目标：自动点击界面中的按钮、菜单、常见交互入口，判断“是否真的有实现”。

扫描对象建议限定为：
- `button`
- `a[href]`
- `[role="button"]`
- 带 `data-testid` / `data-action` 的元素（强烈推荐）

判断“是否有效实现”的信号（命中任意即可算“有动作”）：
- 发生了路由跳转（URL/路由状态变化）
- 弹窗/抽屉出现（DOM 新增可识别容器）
- 发出了网络请求（Web）或 IPC 调用（Electron，可用日志/封装层埋点）
- 出现 toast/snackbar/加载态
- 页面出现可观测的数据变化（表格行数、字段值变化等）

并记录以下取证：
- 点击前后截图（或失败时截图）
- console 日志与错误
- network/IPC 记录（若可采集）

---

## 4. 让自动化“靠谱”的关键：给 UI 打标（强制约定）

如果没有稳定标识，自动点击会很容易“误点/漏点/误判”。建议团队统一增加：

### 4.1 data-testid（定位稳定）
- 页面级：`data-testid="page-sales"`
- 关键按钮：`data-testid="btn-create-order"`
- 弹窗：`data-testid="modal-create-order"`

### 4.2 data-action + 完成度标记（让扫描能判断占位）
建议约定：
- 已实现：`data-action="create-order"`
- 未实现占位：`data-not-implemented="true"`（扫描直接归类为 🔜）
- 暂时禁用：`aria-disabled="true"` + 对应原因（tooltip/说明）

---

## 5. 报告如何呈现（让团队一眼看懂）

### 5.1 feature-inventory（建议表格）
- 模块
- 页面/路由
- 功能点/按钮
- 状态（✅/🟡/🔜/❌/🧪）
- 证据链接（截图/日志）
- 负责人（角色/人）
- 备注/阻塞原因

### 5.2 scan-report（建议统计 + Top 问题）
包含：
- 覆盖页面数、扫描到按钮数、失败数
- Top 10 未实现/故障入口
- 与上次相比的变化（新增完成/新增故障）

---

## 6. 如何进入“版本循环迭代”

1. **每周/每个里程碑**跑一次扫描，更新 `feature-inventory.md`
2. PM 基于 inventory 把条目转换为 `TASK-NNN`（写入 PRD/版本规划）
3. 每个版本固定 Gate：
   - 功能（QA）✅
   - UI/交互（线上测试工程师）✅
   - 安全 ✅
   - 性能 ✅
   - **功能完成度扫描报告已更新** ✅
4. 版本发布后把本次扫描报告归档，形成可追溯的迭代历史
