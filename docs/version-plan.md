# 版本规划（Version Plan）

> 用途：基于 PRD + 功能完成度清单（feature-inventory）+ 扫描报告（feature-scan-report）制定版本迭代计划。

---

## 版本 v0.x.0（目标日期：YYYY-MM-DD）

### 1) 包含任务
- [ ] TASK-xxx：任务描述（P0/P1/P2）

### 2) 修复清单（来自扫描/线上测试/QA）
- [ ] FIX-xxx：问题描述（来源：feature-scan / release-test / QA）

### 3) 不包含（延期到下版本）
- TASK-xxx：延期原因

### 4) 版本验收标准
- 所有 P0 任务完成
- P1 完成率 ≥ 80%
- 无 Critical/Major Bug
- 发布门槛：功能 ✅ + UI/交互 ✅ + 安全 ✅ + 性能 ✅ + 完成度盘点 ✅
