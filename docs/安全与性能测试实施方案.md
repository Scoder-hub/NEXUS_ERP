# 安全与性能测试实施方案（Electron + Web）

> 目标：在“动效增加、功能增多”的情况下，把 **安全风险** 与 **性能退化** 变成可测、可比较、可回归的门槛。  
> 原则：先有**基线**（Baseline），再做**回归**（Regression）；先做“低成本高收益”的检查，再逐步加深。

---

## 1. 发布门槛（建议写入流程）

每次发布前至少满足：

1) **安全基线通过**（见第 2 节）  
2) **性能基线不退化**（见第 3 节）  

产出物建议固定为：
- `docs/security-report.md`（或合并进审查/测试报告的安全章节）
- `docs/performance-report.md`（或合并进发布记录的性能章节）

---

## 2. 安全测试（Security）

### 2.1 Electron 安全基线（必须项）
- [ ] `contextIsolation=true`
- [ ] `nodeIntegration=false`
- [ ] preload 只暴露最小 API（不要暴露 `eval`、任意文件读写、任意 IPC）
- [ ] IPC 通道白名单（channel 常量统一管理）+ 参数校验（Zod/类型）
- [ ] 错误信息不直出：不要把底层 SQL/堆栈信息直接回传到 UI
- [ ] 敏感数据不落日志：密码哈希、PIN、token、个人隐私字段不得出现在日志/前端存储

### 2.2 依赖与供应链风险（低成本高收益）
建议每次发布前跑：
- `npm audit`（记录结果与处置：升级/忽略理由）
- 锁文件/依赖变更审查：新增依赖必须说明用途与风险

### 2.3 Web/Electron 通用安全测试用例（QA/线上测试可执行）
- 权限：无权限用户访问受限页面/操作 → 必须被阻止（前端隐藏 + 路由/后端双校验）
- 输入：超长、特殊字符、空值、边界值 → 不崩溃、不泄露内部错误
- 导出/日志：导出内容不包含敏感字段；错误提示不包含表名/SQL/堆栈
- 本地存储：token/remember-me 等是否按策略加密/过期

---

## 3. 性能测试（Performance）

### 3.1 最需要盯的 4 个指标（建议先定这四个）
1. **启动耗时**：冷启动到首页可交互时间
2. **关键交互响应**：点击按钮→弹窗出现/请求发出/页面切换的耗时（P95）
3. **动画流畅度**：关键动效场景 FPS/卡顿（尤其是列表、图表、弹窗）
4. **资源体积**：渲染进程 bundle 体积与增长趋势（避免动效与依赖把包体撑爆）

### 3.2 Electron 性能关注点（常见坑）
- 主线程阻塞：大计算/大量 JSON 处理/同步 IO 会导致动画与点击卡顿
- 长列表/大表格：虚拟列表、分页、避免一次渲染太多节点
- 图表渲染：数据量大时需要降采样/节流
- 动效：避免频繁触发 layout（offsetWidth/scrollTop 读写交替），优先 transform/opacity

### 3.3 基线记录（必须先做，才能谈优化）
建议 DevOps 在每次发布记录里附上（哪怕先手工记录）：
- 版本号、构建产物大小（renderer js/css）
- 冷启动耗时（人工计时也行，先有对比）
- 关键页面（仪表盘/列表页）滚动与弹窗操作的体感结论（卡/不卡）

后续再升级为自动采集（例如 Playwright trace、performance API、Electron 性能日志）。

---

## 4. 优化策略（遇到问题怎么修）

### 4.1 动效导致卡顿
优先顺序：
1) 找出是否有同步阻塞（大计算/同步 IO）  
2) 减少渲染量（拆分组件、memo、虚拟列表）  
3) 动画用 transform/opacity，避免触发布局  
4) 降级策略：低性能场景减少阴影/模糊/高频动画  

### 4.2 弹窗/下拉遮挡（性能+体验）
优先使用 Portal 到顶层容器，避免被父级 overflow 裁剪；必要时统一弹层容器与 z-index 体系。

### 4.3 产物体积增长
优先顺序：
1) 查新增依赖（尤其动效库/图表库）  
2) 路由级懒加载 / 分包  
3) 移除未使用依赖与样式  

---

## 5. 最小落地计划（现在就能开始）

第一周（最低成本）：
- [ ] 确认 Electron 安全基线（2.1）逐条满足
- [ ] 发布前跑一次 `npm audit` 并记录处置
- [ ] 在发布记录里增加 3 条性能基线：renderer 体积/启动耗时/关键交互体感结论

第二周（自动化）：
- [ ] 把安全/性能检查命令固化到发布脚本/CI
- [ ] Playwright 增加：关键路径 trace + 基本性能断言（如页面可交互时间阈值）
